# 奶龙桌宠 🐲

一只住在你桌面上的奶龙，可以陪你互动、放歌、显示歌词。

## 功能

- 🐣 **小奶龙 / 🐲 大奶龙** 双形态，随时切换
- 💗 **4 种互动**：摸头、打招呼、递水、弹脑瓜崩
- 🎵 **网易云音乐**：扫码登录后搜索播放，歌词以气泡形式显示在桌宠上方
- 🖱️ **左键点击** = 摸头互动，**拖动** = 移动位置，**右键** = 菜单
- 📋 **系统托盘**：快速控制播放、切换形态、打开设置面板
- ⚙️ **设置面板**：音量、大小、置顶、歌词开关、陪伴统计

## 快速开始

双击 `启动奶龙桌宠.bat` 即可（首次运行会自动安装依赖）。

或命令行启动：
```bash
.venv\Scripts\python.exe main.py
```

## 网易云音乐使用

1. 右键桌宠 → 「音乐面板」（或托盘 → 「打开小屋」）
2. 点击「扫码登录」，用网易云音乐 APP 扫码
3. 登录后搜索歌曲，双击播放
4. 歌词会自动显示在桌宠上方的气泡中

> 未登录也能搜索和播放部分免费歌曲，登录后可播放 VIP 歌曲和你的歌单。

## 项目结构

```
Deskpet/
├── main.py                  # 主入口（自动启动 API 服务）
├── pet_window.py            # 桌宠窗口（透明、拖拽、动画、歌词气泡）
├── control_panel.py         # 控制面板（登录、搜索、播放、设置）
├── music_player.py          # 音乐播放器（播放、歌词同步）
├── netease_api.py           # 网易云 API 客户端（走本地中转）
├── settings.py              # 设置持久化
├── tools/process_images.py  # 素材处理脚本
├── assets/                  # 桌宠素材
│   ├── small/               # 小奶龙
│   ├── big/                 # 大奶龙
│   └── tray.png             # 托盘图标
├── data/                    # 用户数据（设置、登录态）
├── node_modules/            # 网易云 API 服务
├── .venv/                   # Python 虚拟环境
└── 启动奶龙桌宠.bat          # 一键启动
```

## 技术栈

- Python 3 + PySide6（GUI、音乐播放）
- Node.js + NeteaseCloudMusicApi（本地 API 中转服务）
- 素材：用户提供，仅供个人使用
